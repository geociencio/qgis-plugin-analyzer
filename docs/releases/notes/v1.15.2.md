# v1.15.2: B102/B307 False-Positive Fix 🎯

Patch release. It removes a false positive introduced with the restored security
scanner in v1.15.1: the `exec`/`eval` rule matched **method** calls such as
`QDialog.exec()`, so ordinary Qt GUI code was reported as arbitrary code
execution.

## Fixed

- **`B102`/`B307` no longer match attribute calls.** `check_exec_eval` used the
  callee *name*, which for `ast.Attribute` calls is the method name — so
  `dialog.exec()`, `self.dlg.exec()` and `table.eval()` were flagged as the
  builtins. The rule now flags only bare-name calls (`exec(...)` / `eval(...)`)
  and ignores attribute/method calls. Two regression tests guard it.

## Notes

- No rule-id, CLI or output-contract changes. Drop-in patch.
- Expect the false-positive findings on Qt-style `.exec()` to disappear;
  genuine builtin `exec`/`eval` usage is still reported.
