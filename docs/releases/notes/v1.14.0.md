# v1.14.0: Analyzer Generalization & Qt6 Readiness 🚀

This release generalizes the analyzer to audit **any** QGIS plugin, not just a single project. It ports the mature AST-based i18n rule, adds a cyclomatic-complexity gate for CI, ships Qt6 migration rules (drop-in parity with `flake8-qgis` `QGS4xx`), and raises the Python floor to 3.11.

## What's Changed

### i18n by AST (no more heuristics)
- The `I18nVisitor` now uses a portable AST rule that recognizes both `self.tr()` and `QCoreApplication.translate()` wrappers.
- Docstrings and technical strings (CSS/HTML, format specifiers, file extensions, color codes, QSettings keys) are correctly excluded.
- Inline `# no-i18n` and `# noqa` comments suppress false positives.
- Per-project tuning via `extra_ignore_calls` / `extra_exact_ignores` under `rules.MISSING_I18N`.

### CI Output Contract
- `project_context.json` now embeds `schema_version`, `analyzer_version`, `analyzed_at` and `project_path`.
- `analyze --json` emits machine-readable JSON to stdout (logs routed to stderr); `--include-content` opts into embedding source.

### Cyclomatic Complexity Gate
- `analyze --max-cc N` fails the analysis (exit 1) when any function exceeds the threshold, and reports `cc_gate` / `cc_violations` in `--json`.

### Qt6 Migration Rules (QGS4xx parity)
- 11 new `QT6_*` rules detect APIs removed in Qt6: `qApp`, `QRegExp`, `QDesktopWidget`, removed enums, `QFontMetrics.width()`, `QComboBox.activated[str]`, compiled resources, multi-arg `addAction`, `QVariant()`, and legacy `QDateTime` signatures.

### Stale Cache Detection
- `summary` now compares cached results against the actual analyzed project and reports a human-readable age plus the changed files.

### Platform & Packaging
- Python floor raised to `>=3.11`; the minimal TOML parser was dropped in favor of stdlib `tomllib`. Type annotations modernized to PEP 585/604.
- License metadata switched to an SPDX expression; deprecated classifier removed.
