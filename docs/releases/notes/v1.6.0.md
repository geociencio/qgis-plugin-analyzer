# Release Notes - v1.6.0 🛡️

**Date**: 2026-02-03
**Tag**: `v1.6.0`

## 🚀 Overview

Version 1.6.0 is a milestone release that brings **Official QGIS Repository Validation** features to your local development environment. This release significantly bridges the gap between local development and the official plugin approval process. Additionally, a major architectural refactor of the CLI and analysis visitors ensures long-term maintainability and performance.

---

## ✨ Key Features

### 🏢 Official Repository Validation (Local)
You can now run the same checks as the QGIS Repository Bot before uploading your plugin:
- **Package Size Validator**: Immediate warning if your plugin exceeds the 20MB official limit.
- **Binary File Guard**: Scans for prohibited files (`.exe`, `.dll`, `.so`, `.pyc`, etc.) that cause instant rejection.
- **Strict Metadata Audit**: Enhanced validation of `metadata.txt`, ensuring mandatory fields (like 'about') are present and URLs follow safe protocols.
- **Folder structure Check**: Verifies that your project structure complies with QGIS standards.

### 🛡️ Enhanced Security Scanning
- **Deep Scan Mode**: Use `qgis-analyzer security --deep` for a more intensive, multi-phase AST audit.
- **CWE Mapping**: All security findings are now mapped to Common Weakness Enumeration IDs for standardized reporting.
- **Secret Scanner Improvements**: Better entropy detection for hardcoded passwords and tokens.

### 🏗️ Architectural Refactoring
- **Command Pattern CLI**: The entire command-line interface has been rewritten using the Command Pattern. Subcommands like `analyze`, `fix`, `summary`, and `security` are now isolated, modular, and easier to extend.
- **Modular Visitors**: The once monolithic `visitors.py` has been decomposed into specialized modules within the `analyzer.visitors` package, improving analysis precision and speed.

## 🐞 Bug Fixes & Improvements
- **Zero-result bug**: Fixed an issue where single-file analysis sometimes reported 0 findings.
- **Path Resolution**: Fixed inconsistent path reporting in terminal summaries.
- **Type Safety**: Achieved >95% type hint coverage for parameters across the core engine.
