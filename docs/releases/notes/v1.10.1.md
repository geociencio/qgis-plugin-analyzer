# Release Notes v1.10.1: Async Metrics Precision ⚡

This maintenance release fixes a critical discrepancy in quality metric calculations for modern QGIS plugins that make extensive use of asynchronous programming.

## 🚀 What's New

### Native Support for `AsyncFunctionDef`
The AST analysis engine (`MetricsVisitor`) has been updated to include processing of asynchronous functions (`async def`).

Previously, the analyzer omitted these functions from its coverage counts, causing **Return Type Hint Coverage** to show artificially low values in projects using `QgsTask` or `async/await` patterns.

## 🛠️ Fixes and Improvements
- **Metrics Visitor**: Implemented `visit_AsyncFunctionDef` for full parity with synchronous functions.
- **Docstrings & Types**: Validation methods now transparently accept both types of function definitions.
- **Bug Investigation**: Documented and resolved the error report regarding multi-line signatures (confirming AST usage was already correct).

## 📊 Impact on Score
Projects with high asynchronous content will see a significant and more accurate increase in their metrics for:
- Type Hint Coverage.
- Docstring Coverage.
- Cyclomatic Complexity (now capturing the complexity of async methods).
