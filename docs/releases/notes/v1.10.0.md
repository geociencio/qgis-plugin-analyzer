# v1.10.0: Precision Architecture & Stability Score Fix 🛡️

We are proud to announce the release of **QGIS Plugin Analyzer v1.10.0**, a maintenance release focused on **architectural accuracy and elimination of false positives**.

This release addresses a critical issue in the dependency graph engine that affected large-scale projects, ensuring that the **Module Stability Score** now reflects the true quality of your codebase.

## 🚀 Key Highlights

### 🧠 Intelligent Dependency Graph
- **Zero False Positives**: The cycle detection engine has been upgraded to ignore `TYPE_CHECKING` imports and validate file existence, eliminating ghost cycles.
- **Canonical Deduplication**: Cycles are now reported exactly once, preventing score inflation.
- **Accurate Stability Score**: Projects with >100 files will no longer see their stability score drop to 0 due to artifactual cycles.

## 📋 Full Changelog

### Fixed
- **Architectural Analysis**: Resolved all false positives in circular import detection.
- **Reporting**: Module Stability Score is now accurate and actionable.
