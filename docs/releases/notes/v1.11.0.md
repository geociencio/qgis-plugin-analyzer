# Release Notes v1.11.0: Robust Project Discovery & Dynamic Versioning 🛡️

## Overview

This release introduces major improvements to the analyzer's core engine, focusing on reliability in project identification and streamlining project maintenance through dynamic versioning.

## 🚀 What's New

### 📁 Robust Project Discovery
One of the most significant improvements in this version is the fix for **Project Type Detection**. Previously, the analyzer could misidentify a QGIS plugin as a "Generic Python Project" if the `metadata.txt` file was matched by patterns in `.analyzerignore`.

- **Technical Fix**: The file discovery logic has been adjusted to identify mandatory QGIS metadata **before** applying any ignore filters.
- **Impact**: Ensures that critical QGIS compliance rules and PyQGIS-specific visitors are always executed for plugins.

### 🔄 Dynamic Versioning System
We've eliminated hardcoded version strings from the codebase. The `__version__` attribute in `src/analyzer/__init__.py` is now dynamically resolved from `pyproject.toml`, ensuring the CLI always reports the correct version in both production and development modes.

## 🛠️ Fixes and Improvements
- **Engine Logs**: Removed redundant "Project type" log entries during the analysis phase.
- **Metadata Consistency**: The internal `has_metadata` flag is now a reliable indicator across all scanning phases.
- **Path Handling**: Improved resolution of project roots for more accurate metadata detection.

## 📦 How to Upgrade

If you installed via `uv`:
```bash
uv tool upgrade qgis-plugin-analyzer
```

If you installed via `pip`:
```bash
pip install --upgrade qgis-plugin-analyzer
```
