# v1.16.0: Incremental Cache & Unified Rule Registry ⚡📜

Minor release. Two features and a set of quality/behavior refinements: repeated
analyses are now incrementally cached, and the rule catalog is a single source of
truth that drives `list-rules` and a generated `RULES.md`.

## Added

- **Incremental analysis cache.** Per-file, content-hash keyed, with real
  invalidation (analyzer version + a fingerprint of the analyzer source, the
  resolved project path, and the effective rules/scope/content/type). Only
  changed files are re-analyzed; results are sorted by path for deterministic
  output. Disable with the new **`--no-cache`** flag (also honoured by
  `security`).
- **Unified rule registry + generated `RULES.md`.** `src/analyzer/rules/` is now
  the source of truth for all **51** rules (regex + AST/visitor + security +
  secrets + patterns). `list-rules` lists every rule grouped by category and adds
  **`--format text|markdown`**; `scripts/generate_rules_md.py` renders `RULES.md`
  (a test fails on drift, so the docs can't go stale).
- Security/secret rule ids are enumerable (`SecurityRegistry.rule_ids()`,
  `SecretScanner.rule_ids()`), enabling the anti-drift tests.

## Changed

- **Emitted severity follows the rule catalog** (per-rule high/medium/low)
  instead of defaulting every AST issue to `medium`. A profile
  `[tool.qgis-analyzer.profiles.<p>.rules]` entry still overrides per rule.
- **`MISSING_I18N` is no longer emitted for `generic` (non-Qt) projects** under
  the default `all` scope — the rule is Qt-specific (`self.tr()`). `analyze i18n`
  and profile overrides still run it.
- `list-rules` now covers all **51** rules (previously 7 regex rules only).
- Self-analysis noise removed (all missing docstrings/type hints fixed, magic
  numbers extracted to named constants, `NON_PYTHONIC_LOOP` narrowed to manual
  *index* management); modules over 400 lines split.

## Notes

- **Behavior changes to be aware of** (consumers of `project_context.json`):
  issue `severity` values are now rule-specific rather than always `medium`;
  `MISSING_I18N` disappears from `generic` projects' default runs. Rule ids,
  CLI command names and the JSON schema keys are unchanged.
- New CLI surface: `analyze --no-cache`, `security --no-cache`,
  `list-rules --format {text,markdown}`.

## Quality

- 233 tests; `ruff check` + `mypy src/` clean; self-analysis `--max-cc 15` green;
  every module ≤ 400 lines; Security 100/100. Self-run findings reduced to 10
  (all LOW: `SPAGHETTI_CODE`/`GOD_OBJECT`).
