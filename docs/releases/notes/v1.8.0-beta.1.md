# v1.8.0-beta.1: I18n Precision & Docstring Optimization 🌐

This release introduces critical improvements to the QGIS Internationalization (i18n) analysis engine, ensuring developer documentation is respected while maintaining high standards for user-facing string detection.

## Key Highlights

### 🛡️ Differentiated i18n Analysis
The tool now properly distinguishes between technical documentation (docstrings) and actual user-facing messages. This prevents false positives in compliance scores while ensuring that no string intended for the end-user goes untranslated.

### 🔍 Enhanced UI Heuristics
Short UI labels (e.g., "Name:", "Error!") are now correctly identified as translation candidates. This improvement ensures that even the smallest UI elements meet internationalization standards.

## What's Changed
- **[NEW]** Standalone string detection logic to exclude docstrings from `MISSING_I18N` checks.
- **[FIX]** Refined string heuristics to include multi-punctuation suffixes common in GIS interfaces.
- **[TEST]** Added a dedicated test suite for i18n standards maintenance.

*This is a beta release intended for validation in complex PyQGIS environments.*
