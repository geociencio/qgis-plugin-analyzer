# v1.7.0: High-Performance Engine & Safety Audit 🛡️

We are excited to announce the release of **QGIS Plugin Analyzer v1.7.0**. This version introduces a major architectural overhaul and new advanced auditing capabilities to ensure QGIS plugins are safe, efficient, and AI-ready.

## 🚀 Key Highlights

### ⚡ Single-Pass Engine (Performance Phase)
The analysis engine has been completely refactored to use a true **Single-Pass AST Traversal**.
- **9x Redundancy Reduction**: Specialized visitors now subscribe to node hooks, visiting each file's AST only once.
- **Worker Context Sharing**: Optimized parallel processing by sharing configuration and project metadata across processes, significantly reducing startup overhead for large-scale plugins.

### 🛡️ Deep QGIS Safety Audit
New rules to detect common runtime hazards in QGIS plugins:
- **Signal Leak Detection**: Automatically flags Qt signals that are connected but never disconnected, preventing crashes during plugin unloads.
- **UI-Blocking Heuristics**: Identifies intensive operations (like `getFeatures` loops) that should be moved to `QgsTask` to keep the QGIS interface responsive.

### 📊 Visualization & Utilities
- **Dependency Graphing**: Use the new `graph` command to generate Mermaid diagrams of your plugin's internal dependencies and circular imports.
- **Instant Report Viewer**: The new `serve` command starts a local web server to view analysis results without manually navigating the file system.
- **Refined Complexity Scoring**: Introduced a density-based penalty that more accurately reflects the maintenance difficulty of logic-dense code.
