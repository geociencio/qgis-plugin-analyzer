# Release v1.12.0: Gen 5 Architecture & Precision Analytics 🛡️

We are excited to announce version 1.12.0 of `qgis-plugin-analyzer`, bringing significant architectural improvements and enhanced precision to our static analysis engine.

## 🚀 What's New

### Gen 5 Framework Upgrade
The agentic framework powering our workflows has been modernized to the **Generation 5 Architecture**. 
- **English-Based Workflows:** All internal agents, prompt structures, and workflows are now fully standardized in English for maximum portability and compatibility with cutting-edge MCP logic.
- **Specialized Skills Modules:** We've integrated dedicated skills including `agentic-memory` and `domain-logic` to enforce high standards.

### Scaffold Blueprints System
We introduced the `scaffold` blueprints functionality, allowing for standardized generation of QGIS and specialized mining plugins straight from the CLI.

## 🛠️ Fixes & Enhancements

- **Smart Cache Invalidator:** The `summary` command will now detect if your source files are newer than the cached analysis results, displaying a prominent warning if the results might be "phantom" or stale.
- **High-Precision Type Hint Parsing:** Refactored the AST parsing logic in `metrics_visitor.py`. The engine now robustly identifies return type hints even when function signatures span multiple lines (due to strict formatting like Black), eliminating false positive `MISSING_TYPE_HINTS` detections.
- **Codebase Cleanups:** Upgraded global compliance with `ruff` and `black`, dropping technical debt to virtually zero.

## 📦 Installation & Upgrades

```bash
uv pip install --upgrade qgis-plugin-analyzer
```
