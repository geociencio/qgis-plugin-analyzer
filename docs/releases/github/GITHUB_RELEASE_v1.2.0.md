# v1.2.0: The Integration Release

This release introduces native support for **GitHub Actions** and **Pre-commit Hooks**, streamlining CI/CD integration for QGIS plugin developers.

## 🚀 New Features
- **GitHub Action**: `uses: geociencio/qgis-plugin-analyzer@v1.2.0`
- **Pre-commit Hook**: native hook id `qgis-plugin-analyzer`
- **PyPI Compliance**: Fully modernized metadata for 2025 standards.

## 📦 Installation
```bash
pip install qgis-plugin-analyzer==1.2.0
# or via uv:
uv add qgis-plugin-analyzer
```
